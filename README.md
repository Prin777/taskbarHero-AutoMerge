# TBH 自动合成工具

这是一个面向 Windows 11 的《TBH: Task Bar Hero》本地鼠标自动化工具。当前版本为 `0.2.3`，只处理“装备”和“材料”，不读取游戏进程、存档或网络数据。

## 功能概览

- 程序启动后立即执行一轮，之后每隔 5 小时执行。
- 通过画面截图判断九宫格是否全部填满，只有稳定识别为 `9/9` 才点击合成。
- 自动处理“装备”和“材料”，不处理“饰品”，合成优先级沿用游戏内置逻辑。
- 仅在已校准的游戏窗口位于前台时操作鼠标。
- 支持自动识别位置、手动校准、F8 暂停/恢复、F9 紧急停止。
- 自动识别失败时保存现场截图，运行过程记录各格图像差异值。

## 使用前提

- Windows 11。
- 游戏使用简体中文界面。
- 自动化运行期间，游戏窗口大小和界面比例应与校准时一致。
- 从源码运行或自行构建需要 Python 3.11 或更高版本。

## 当前行为

- 程序启动或首次校准完成后立即执行一轮，不检查背包是否已满。
- 不检测也不修改“包含仓库物品”，直接执行合成。
- 依次处理“装备”和“材料”，不处理“饰品”。
- 每个类别执行以下流程：
  1. 点击“自动填充”。
  2. 稳定识别九宫格，只有 9 格全部填满才点击合成。
  3. 若不足 9 格，点击左侧退回按钮，再次自动填充复核。
  4. 第二次仍不足 9 格，则再次退回物品，并判定当前类别处理完毕。
- 两个类别都完成后等待 5 小时，再开始下一轮。5 小时从上一轮完成时开始计算。
- 仅在已校准的游戏窗口位于前台、尺寸未变化且操作区域未被遮挡时点击。
- 单类别每轮最多合成 100 次，超时或异常会自动暂停，避免死循环。

## 快捷键与状态

- `F8`：开启或暂停托管。
- `F9`：紧急停止并取消当前一轮。
- “立即执行”：忽略剩余倒计时，开始新一轮。
- 状态窗口会显示托管中、等待游戏、暂停、异常和下一轮倒计时。

程序不会主动把游戏切到前台。开始运行后，请自行点击游戏窗口；切换到其他程序时，自动化会在下一次鼠标动作前停止等待。

如果快捷键被其他程序占用，状态窗口会显示红色警告。校准时仍可使用“3 秒后捕获鼠标位置”按钮；F9 注册失败时不要进行无人值守运行，应先关闭占用快捷键的程序并重启本工具。

## 自动识别位置

首次启动会优先打开自动识别。请先打开游戏的背包和魔方合成窗口，并确保：

1. 九宫格完全为空；
2. 游戏使用简体中文界面；
3. 魔方面板没有被其他窗口遮挡。

确认后，工具会隐藏并给出 3 秒时间。点击游戏使其位于前台，程序会按常见界面缩放比例寻找“自动填充”文字，并按识别出的比例推导九宫格、自动填充、类别菜单、合成和退回按钮的位置。置信度不足时不会点击，而是提示使用手动校准，同时把当时的游戏截图保存为 `%LOCALAPPDATA%\TaskbarHeroAutoSynth\auto-detect-failure.bmp` 便于排查。

## 九宫格识别原理

校准时，程序在九个空格中心各保存一张 `16×16` 像素的空状态基准。点击自动填充后，再次截取相同位置，并计算当前图片与空基准的 RGB 平均绝对差异：

```text
差异值 >= 15：该格有物品
差异值 < 15：该格为空
```

程序间隔 0.25 秒重复观察，填充数量连续两次相同后才接受结果。只有稳定得到 `9/9` 才点击合成；第一次不足九格时会退回物品并重新自动填充，第二次仍不足才结束当前类别。

## 手动校准

点击“手动校准”，按照向导依次把鼠标放到指定位置并按 `F7`。类别菜单项校准时，需要手动点开下拉菜单。校准配置保存在：

```text
%LOCALAPPDATA%\TaskbarHeroAutoSynth\config.json
```

两台电脑可以分别使用自动识别；识别失败时再手动校准。游戏窗口可以移动，但改变窗口大小、Windows 显示缩放或游戏界面比例后需要重新识别。

0.2.3 版本增加了多比例、逐像素自动识别，避免大截图中按钮文字刚好位于奇数像素时被快速扫描跳过；同时取消了手动校准结束时容易误判的九格外观相似检查。升级后旧基准会自动失效，需要重新执行一次“自动识别位置”或“手动校准”。第 8 步捕获完成后会直接保存九个空格采样，不会再因为各格背景明暗不同而拒绝保存；因此捕获前仍要由用户确认九宫格确实为空。

## 从源码运行

需要 Python 3.11 或更高版本；运行时只使用 Python 标准库。

```powershell
python taskbar_hero.py
```

运行时不需要安装第三方 Python 库。

## 构建单文件程序

安装 Python 后，在项目目录运行。推荐直接双击 `build.cmd`，或在命令提示符执行：

```bat
build.cmd
```

也可以在 PowerShell 中执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

不要在 CMD 中直接输入 `build.ps1`；CMD 不认识 PowerShell 语法。

脚本会在项目内创建独立构建环境并安装 PyInstaller，最终程序位于：

```text
dist\TBH-AutoSynth.exe
```

把该 EXE 复制到第二台电脑即可；首次启动仍需完成该电脑自己的校准。

如果项目内残留的 `.venv-build` 指向已经卸载的 Python，构建脚本会只删除并重建这个构建环境，不影响源码和配置。

## 项目结构

```text
taskbar_hero.py          程序入口
tbh_automation/app.py   窗口、校准和任务调度
tbh_automation/engine.py 合成状态机
tbh_automation/windows.py Windows 截图、识别和鼠标操作
tbh_automation/autodetect.py 自动位置识别
tbh_automation/model.py 配置模型
tests/                   自动测试
build.cmd / build.ps1    Windows 打包脚本
```

## 测试

```powershell
python -m unittest discover -s tests -v
```

自动测试覆盖多比例和奇数像素位置识别、九格已满、首次不足后复核成功、连续两次不足、类别切换、安全上限、暂停取消、5 小时间隔、配置保存和基础图像识别。

## 注意事项

- 画面识别依赖校准时采集的空九宫格。主题、分辨率、窗口尺寸或界面比例变化后请重新校准。
- 自动鼠标操作不等于游戏官方许可，也无法保证不触发游戏规则或反作弊。请自行确认并承担使用风险。
- 日志位于 `%LOCALAPPDATA%\TaskbarHeroAutoSynth\automation.log`，出现暂停时可用于排查。
