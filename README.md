# TBH 自动合成工具

适用于 Windows 11 的《TBH: Task Bar Hero》自动合成工具，当前版本为 `0.7.3`。

程序通过窗口识别和鼠标操作完成合成，不读取游戏内存、存档或网络数据。它会自动处理“装备”和“材料”，不会处理“饰品”。

## 主要功能

- 自动查找游戏，并在需要时打开英雄背包和魔方合成窗口。
- 自动识别合成界面和按钮位置，无需每次手动摆放窗口。
- 依次处理“装备”和“材料”，仅在合成按钮连续显示为蓝色可用时点击。
- 支持 `1h`、`2h`、`3h`、`5h` 四种下一轮执行间隔，选择后自动保存。
- 支持立即执行、暂停、紧急停止以及 `循环间隔剩余 hh:mm:ss` 状态。
- 自动识别在后台执行，界面会持续显示进度，并可用 `F9` 安全取消。
- 关闭主窗口后继续在系统托盘运行，可从托盘恢复或退出程序。
- 主界面的“关闭自动化程序”会停止全部自动化并直接退出，不在后台或托盘留存。
- 防止重复启动多个程序实例。
- 可按需保存本次会话日志和诊断截图。

## 使用条件

- Windows 11。
- 游戏使用简体中文界面。
- 游戏必须保持运行；程序会自动恢复最小化窗口，但无法移开的置顶遮挡会导致安全暂停。
- 改变游戏窗口大小、Windows 显示缩放或游戏界面比例后，需要重新识别位置。

## 快速开始

1. 启动《Task Bar Hero》，并保持游戏窗口正常显示。
2. 运行 `TBH-AutoSynth.exe`。
3. 首次启动时，根据提示执行“自动识别位置”。通常不需要提前打开背包或魔方窗口。
4. 在主界面选择下一轮间隔：`1h`、`2h`、`3h` 或 `5h`。
5. 完成识别后，程序会立即执行第一轮；以后从上一轮完成时开始计算下一次时间。
6. 点击窗口右上角关闭按钮可隐藏到系统托盘；点击主界面的“关闭自动化程序”可直接完全退出，也可在托盘中选择“退出后台”。

程序会记住校准结果和执行间隔。配置文件保存在：

```text
%LOCALAPPDATA%\TaskbarHeroAutoSynth\config.json
```

## 界面与快捷键

| 操作 | 作用 |
| --- | --- |
| `F8` | 开启或暂停托管 |
| `F9` | 紧急停止并取消当前一轮 |
| 立即执行 | 忽略当前倒计时，开始新一轮 |
| 下一轮间隔 | 选择 `1h`、`2h`、`3h` 或 `5h` |
| 自动识别位置 | 自动查找游戏、打开合成界面并保存按钮位置 |
| 手动校准 | 自动识别失败时，按向导手动捕获按钮位置 |
| 关闭窗口 | 隐藏到系统托盘，后台任务继续运行 |
| 关闭自动化程序 | 取消当前操作、停止后台线程并移除托盘图标，然后退出程序 |

快捷键被其他程序占用时，主界面会显示红色提示。此时请关闭占用快捷键的程序并重启本工具；`F9` 无法注册时不建议无人值守运行。

## 自动合成规则

每轮按“装备 → 材料”的顺序处理：

1. 点击“自动填充”。
2. 最多等待 3 秒，并连续两次确认合成按钮为蓝色。
3. 按钮可用时执行合成，然后继续下一次自动填充。
4. 按钮一直不可用时，退回物品并重新填充复核一次。
5. 第二次仍不可用时结束当前类别。

程序不会修改“包含仓库物品”选项，也不会判断背包是否已满。单个类别每轮最多合成 100 次；遇到识别异常、窗口变化或安全上限时会自动暂停，避免持续误操作。

## 位置识别与手动校准

自动识别会查找 `TaskBarHero.exe` 的 Unity 游戏窗口，必要时发送一次 `Tab` 打开英雄背包，再识别并点击黄色魔方入口。找到“自动填充”按钮后，程序会按当前界面比例计算并保存其他按钮位置。

识别期间主界面不会再被阻塞；状态栏会显示识别进度。游戏窗口冷启动、暂时无法接管前台时，程序会安全等待并重试，不会在首次激活失败后直接停止。需要中止时可按 `F9`。

如果自动识别失败：

1. 确认游戏正在运行且使用简体中文。
2. 移开遮挡游戏操作区的置顶窗口。
3. 保持游戏窗口大小和显示缩放稳定后重试。
4. 仍然失败时选择“手动校准”，按向导将鼠标移动到指定按钮并按 `F7`。

游戏窗口可以移动，但改变窗口大小、显示缩放或界面比例后应重新识别。

## 日志与故障排查

“保存本次会话日志和诊断截图”默认关闭。需要排查问题时，先勾选该选项再重现问题，程序会创建：

```text
diagnostics\日期时间\
```

目录中包含本次会话的 `session.log`、自动识别阶段截图和合成按钮状态截图。程序目录不可写时，会改存到 `%LOCALAPPDATA%\TaskbarHeroAutoSynth\`。

提交问题时建议直接压缩整个会话目录，而不是只提供错误弹窗。诊断资料可能包含当时可见的游戏画面，请在分享前自行检查。

## 注意事项

- 本工具会主动移动鼠标并点击游戏界面，运行期间请避免同时操作鼠标。
- 画面识别依赖当前游戏界面样式；游戏更新后如果识别异常，请立即按 `F9` 停止并重新校准。
- 自动化工具不代表获得游戏官方许可，也不能保证符合游戏规则或反作弊要求，请自行评估使用风险。
- 若发现点击位置异常、窗口识别错误或其他不可预期行为，请立即按 `F9`，不要继续无人值守运行。

## 从源码运行

需要安装带有 Tkinter 的 Python 3.11 或更高版本：

```powershell
python -m pip install -r requirements.txt
python taskbar_hero.py
```

## 构建 EXE

在项目目录运行：

```bat
build.cmd
```

构建脚本会建立独立环境、安装依赖并生成单文件程序：

```text
dist\TBH-AutoSynth.exe
```

构建成功前不会替换已有 EXE；生成后还会校验程序图标。运行测试可使用：

```powershell
python -m unittest discover -s tests -v
```
